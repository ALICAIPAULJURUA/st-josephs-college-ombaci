# Image credits

The project has no school-supplied photos or verified reusable photos of St. Joseph's College, Ombaci. A Wikimedia Commons search for the school's name returned no image results. The Commons API was rate-limited during follow-up licence checks, so no Commons images were downloaded.

The following locally hosted sample photos are used for general facilities, student-life atmosphere, and sports imagery. They are not photographs of St. Joseph's College, Ombaci. Each is marked as a sample in the media library; the Dashboard lists them for replacement. Samples showing people are marked `hasPeople = true`. No sample portraits are used for named staff, Old Boys, or achievements.
